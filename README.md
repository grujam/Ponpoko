# Ponpoko
폰포코 너구리 게임

## 렌더링
DXManager로 텍스처 또는 SolidTexture를 통해 매 프레임 마다 렌더링 적용합니다.
D3DX 및 DX9 활용

## 맵 에디터
상단 버튼을 통해 추가할 객체 선택
발판: 두번의 클릭을 통해 해당 길이 만큼 발판 추가
적, 아이템, 스파이크: 발판 위에 추가
사다리: 한 층에 하나만 추가, 두 개의 발판 사이에만 추가 가능

## 게임 플레이
이동: 방향키
점프: 스페이스바

모든 아이템을 획득하면 다음 레벨로 넘어갑니다

## 네트워크
한 명이 호스트로 시작 시 다른 쪽에서 IP로 연결 진행
TICK 단위로 동기화
